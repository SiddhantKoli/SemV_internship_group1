HEC-RAS INPUT CHECKLIST — VADHAVAN / PALGHAR

Required before creating a defensible coastal 2D event plan:
[ ] Agreed study-area boundary and event purpose (screening, hindcast, or design case)
[ ] Land DEM and nearshore/offshore bathymetry with documented common vertical datum
[ ] Surveyed or authoritative channels, drains, embankments, roads, seawalls, gates, and culverts
[ ] Coastal water-level time series (tide plus storm surge) with station, datum, time zone, and source
[ ] Catchment inflow hydrographs if rainfall/runoff enters the domain
[ ] Land-cover-based Manning n values and provenance
[ ] Initial water level, simulation period, output interval, and stable computational time step
[ ] Observed flood extent/depth/high-water marks for calibration or validation
[ ] Reviewer approval of mesh, boundary placement, structures, and sensitivity cases

Current project has terrain only. Do not invent or silently substitute these inputs.
